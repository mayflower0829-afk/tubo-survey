# 乡橙调查 · TuboSurvey

**三创赛国家级一等奖项目「启子智选·土拨购乡橙」的市场调查数据交互分析平台**——把市场调查报告的 400 条样本与全部统计结论，做成可交互验证的在线系统。

**在线平台**：<https://cloud1-d4gsgj705497df85d-1501559031.tcloudbaseapp.com/survey/>

## 功能

- **总览**：配额抽样样本结构、购买意愿 34.75%、接受总价中位数 ¥95、量表 α 均值
- **频数分析**：8 个变量任意切换，柱状图 + 频数占比表
- **交叉分析**：r×c 卡方独立性检验（χ²、p 值、Cramér's V、期望频数条件检查），行/列任意组合 + 100% 堆叠图
- **量表与相关**：四个量表 Cronbach's α、Spearman 秩相关 4×4 热力图与结论
- **方法说明**：抽样方案、问卷结构、数据声明

## 数据诚实声明

400 条记录为**按调查方案生成的模拟问卷数据**（非真实发放回收），分布与统计结论已校准至《市场调查报告》口径；生成逻辑固定随机种子，可复现。页面显著位置同步此声明——数据来源诚实是市场调查的伦理底线。

## 正确性验证

统计函数为**前端手写实现**（无统计库依赖）：

- 卡方上侧概率：不完全伽马函数（级数 + 连分式双分支）
- 基准点交叉验证：χ²=8.73/df=3 的 p 值与 `scipy.stats.chi2.sf` 一致（0.033105 vs 0.0331）；χ²=3.84、χ²=6.63 两个理论临界点的复现误差 <0.1%；退化情形（χ²=0→p=1）正确
- Spearman：平均秩处理 + t 近似 p 值；Cronbach's α：标准公式
